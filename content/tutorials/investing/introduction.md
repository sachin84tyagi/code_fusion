# Hum Kya Seekhenge?

Is course mein hum **Wyckoff Method + Volume Spread Analysis (VSA)** seekhenge.

Yeh do cheezein ek saath mili toh ek complete system banti hai:

```
Wyckoff = Market structure samajhna (phases, schematics)
VSA     = Har individual bar ka logic samajhna (volume + spread + close)
```

Dono milake bataate hain:
- **Kaun kya kar raha hai** (buyers, sellers, professionals)
- **Kab kar raha hai** (market phase)
- **Kyun kar raha hai** (supply/demand logic)

---

# Course Ka Core Philosophy

> **Hum signals rote nahi. Hum logic samajhte hain.**

Galat approach:
```
No Demand bar dikha → Sell karo
```

Sahi approach:
```
No Demand bar kahan aaya?
Background mein kya tha?
Volume kaisa tha?
Agli bars kya confirm kar rahi hain?
Tab decision lo.
```

# Har Topic Mein 5 Sawal

Har VSA signal ke liye hum yeh 5 sawaal poochenge:

```
1. Background kya hai?         → Context check
2. Bar kaisi hai?              → Visual bar analysis
3. Volume kaisa hai?           → Effort check
4. Close kahan hai?            → Result check
5. Agli bars confirm kar rahi hain? → Confirmation
```

Jab tak yeh 5 sawaalon ke jawaab nahi milte, trade nahi lete.
