## 🎯 Teaching Method (How Every Lesson Works)

Every lesson follows this adventure sequence:

```
📡 SHOW  →  📖 EXPLAIN  →  ✍️ PRACTISE  →  🎮 PLAY  →  📊 REVIEW
```

1. **SHOW** — Short cinematic sci-fi scene introduces new German
2. **EXPLAIN** — Meaning + Pronunciation + Memory trick (in Hinglish)
3. **PRACTISE** — You try it yourself before seeing the answer
4. **PLAY** — Mission challenge using what you just learned
5. **REVIEW** — Mission Report: what you learned, key phrases, next step

## 🔊 Pronunciation Quick Reference

| Sound | How It Sounds | Example Word | English Comparison |
|:------|:-------------|:-------------|:-------------------|
| `ch` (after i/e) | Soft hiss — like "hyuh" | **ich** (I) | Like "hue" without the vowel sound |
| `ch` (after a/o/u) | Guttural — like clearing throat lightly | **auch** (also) | Like the Scottish "loch" |
| `sch` | Like English "sh" | **schön** (beautiful) | "sh" as in "shop" |
| `ei` | Like English "eye" | **nein** (no) | Like "mine" |
| `ie` | Like English "ee" | **wie** (how/as) | Like "see" |
| `eu` | Like "oy" | **neu** (new) | Like "toy" |
| `ä` | Like "eh" | **Mädchen** (girl) | Like "bed" |
| `ö` | Round lips, say "eh" | **schön** (beautiful) | No exact English match |
| `ü` | Round lips, say "ee" | **über** (over) | No exact English match |
| `w` | Like English "v" | **wie** (how) | Like "vee" |
| `v` | Like English "f" | **vier** (four) | Like "fear" |
| `z` | Like "ts" | **zwei** (two) | Like "tsunami" |

> ⚠️ **Note:** Pronunciation approximations here are helpful guides, not perfect matches. Real German sounds are best learned through listening and practice over time.

## 🌟 German vs Hindi/English — Interesting Parallels

| German | Hindi | English | Fun Connection |
|:-------|:------|:--------|:---------------|
| **Mutter** | Maa / Mata | Mother | Almost same root word! |
| **Vater** | Pita | Father | Related to Latin Pater |
| **Name** | Naam | Name | Sounds almost identical |
| **Wasser** | Paani | Water | German W = English V sound |
| **Haus** | Ghar | House | German "Haus" sounds like "house" |
| **Mann** | Aadmi | Man | Exactly same! |
| **Arm** | Baazoo | Arm | Same word, same meaning |
| **Finger** | Unglee | Finger | Same word! |

> 💡 **Why this matters:** German and English share the same ancient language family (Germanic). Many words will feel familiar — use that to your advantage!

## ⚙️ Course Rules (For Best Results)

1. **Complete missions in order.** Each mission builds on the previous one.
2. **Always attempt the challenge yourself** before reading the answer.
3. **Read German words OUT LOUD** — even if you're alone. Your mouth needs practice.
4. **If you're confused**, re-read the Hinglish explanation before moving to the next section.
5. **Revision is built-in.** Older words appear in newer missions — that's intentional.
